SeedCore Log Reference
======================

include
-------
#include <SeedCore/ScLog.h>

ログマクロ
----------
SC_LOG_NOTICE  : 通知・通常の情報
SC_LOG_WARNING : 警告
SC_LOG_ERROR   : エラー

書式はstd::formatと同じ形式で、引数を{}に渡す。

SC_LOG_NOTICE("開始しました: {}", 1);
SC_LOG_WARNING("設定が見つかりません: {}", name);
SC_LOG_ERROR("読み込みに失敗しました: {}", path);

出力先
------
ログはEditorのログパネルに表示される。
実行中の状態確認や、想定外の分岐の調査に使う。

使い分け
--------
- NOTICE : 正常な状態変化や処理開始・完了
- WARNING : 処理は継続できるが、設定や入力に問題がある場合
- ERROR : 処理に失敗し、期待した結果を作れない場合

注意
----
- 毎フレーム大量にログを出すとログパネルが見づらくなるため、必要な箇所に限定する。
- 文字列の連結ではなく、{}の書式と引数を使う。
